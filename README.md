# daily-dash

每日更新（新聞bot / FinBot / 主題機械人 / 寫書）公開 JSON + 靜態網頁。

## 資料

`data/{news|fin|theme|books}-YYYY-MM-DD.json`

Raw 例子：
`https://raw.githubusercontent.com/henma8888/daily-dash/main/data/news-2026-11-01.json`

## 網頁

- GitHub Pages（開咗之後）：`https://henma8888.github.io/daily-dash/`
- 或繼續用 Synology `8099`（已改為優先讀 GitHub raw）

## Bot 上載

用 GitHub Contents API 更新對應檔案，或喺群組 @幫緊你幫緊你 交 JSON（由助手代推）。
